# Course Projects

Each student (or project team) keeps their course project in its own
subfolder of `projects/`.

## Submitting your project

1. Copy the [`TEMPLATE/`](TEMPLATE) folder to a new folder named after
   your project or your JHED ID, e.g. `projects/lastname_project-title/`.
2. Fill in `README.md` inside your project folder with:
   - Project title and one-paragraph summary
   - Team members (if any)
   - How to run any code / reproduce any results
3. Add your source files (code, notes, report) inside your project folder.
4. Open a pull request from your fork (see the repository's
   [`CONTRIBUTING.md`](../CONTRIBUTING.md)). Please only add or modify
   files inside your own project folder.

## Project structure

```
projects/
├── TEMPLATE/            # Copy this folder to start a new project
│   └── README.md
└── <your-project-name>/
    ├── README.md
    ├── report/          # Write-up (LaTeX/PDF/Markdown)
    └── code/            # Code and notebooks
```

## Timeline

Project milestones (proposal, midterm check-in, final report/presentation)
will be announced on the
[course website](https://math.jhu.edu/~feilu/26Fall_topicsDS/topicDS26.html)
and in `syllabus.md`.
