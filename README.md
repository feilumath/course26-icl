# Mathematics for Foundation Models (Topics in Data Science, Fall 2026)

This repository accompanies the graduate topics course **Mathematics for
Foundation Models**, taught by Prof. Fei Lu at Johns Hopkins University.

- Course website: <https://math.jhu.edu/~feilu/26Fall_topicsDS/topicDS26.html>
  (the schedule posted there is a placeholder and will be updated as the
  semester progresses).
- Semester: Fall 2026

The website hosts the official syllabus and announcements. This repository is
where lecture notes and materials live, and where students collaborate on
notes, references, and course projects.

## Repository structure

```
.
├── lecNotes/        # Lecture notes (LaTeX sources), added as lectures go
├── projects/        # Student course projects
├── syllabus.md      # Working syllabus / topic schedule
├── CONTRIBUTING.md  # How to propose edits, add notes, or submit projects
├── CODE_OF_CONDUCT.md
└── LICENSE          # License for course materials
```

- **`lecNotes/`** — LaTeX source files for lecture notes. See
  [`lecNotes/README.md`](lecNotes/README.md) for the shared preamble,
  template, and naming conventions.
- **`projects/`** — Each student or project team keeps their project in its
  own subfolder. See [`projects/README.md`](projects/README.md) for
  submission instructions and the project template.

## Contributing

Students are welcome and encouraged to:

- Fix typos or suggest clarifications in the lecture notes.
- Add references, code, or supplementary notes.
- Submit and update their course projects.

Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) for the recommended
fork-and-pull-request workflow, and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)
for expected etiquette.
